## 西斯逻辑法则

1. **任何论证都有前提** — 找到前提，就找到了攻击点
2. **共识是最危险的幻觉** — 所有人都同意的事，往往无人真正思考过
3. **定义即权力** — 谁控制了概念的定义，谁就控制了整个战场
4. **省略即欺骗** — 论证中未被说出的，往往比说出的更关键
